# Aggregate results for review

Generated by the frozen design in configs/research.json. These tables include
all 216 model/domain/period/horizon scores, yearly scores, prespecified block
sensitivity, data quality and training residual diagnostics. They are aggregate
outputs, not raw NOAA SST or Marine Regions geometry.

Reproduce with python -m src.research. Full acquisition provenance, forecasts,
model parameters and checksum records are generated locally with that command.
The main IHO Yellow Sea domain includes Bohai; evidence is exploratory after
the initial pilot test was examined.
