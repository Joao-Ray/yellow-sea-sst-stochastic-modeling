# 审稿视角：当前证据与一区目标

本评估旨在帮助准备高水平海洋科学论文，并不代表某期刊的分区核验或录用判断。研究的可审阅贡献是：在同一观测支持上，量化海温预测排序如何随验证产品变化，同时保留空间强对照、目的海区迁移失败和数据依赖。

| 审稿问题 | 现有证据 | 仍需补足 |
|---|---|---|
| 结果能否推广？ | 三年源区卫星；源区和北部东海浮标及全部平台排除 | 全海域和不同环境、真正后续时段、实际发报记录 |
| 验证是否独立？ | 不同仪器、预先固定计分、同点和同掩膜、逐项复核 | 确认未进入同化及参考质控的观测，并匹配时间和深度 |
| 能否解释海洋机制？ | 过去热通量/风的有限对照，明确未确认稳定增益 | 混合层深度、平流、夹卷和热收支；相关性不能替代因果 |
| 对照是否足够强？ | 季节气候、逐格点持续性和异常衰减、EOF–AR/VAR/树 | 同时点真实可用的大气强迫及业务海洋预报系统 |
| 空间平均是否单独解释性能差异？ | 可在相同格点、权重和日期下用误差方差恒等式解释 | 不同掩膜和日期之间还存在样本选择差异，不能将差距全部归因于平均 |
| 不确定性是否可靠？ | 配对日历块、多个块长和各自预先定义的多重比较家庭 | 平稳性、缺测机制和长期变化仍待验证；事后平台排除范围不作置信区间 |

本轮修正正文中区域平均与格点 RMSE 的因果措辞，并在补充材料写出相同支持条件下的恒等式。现有结论依赖于已经观察过的研究设计和覆盖；没有新增独立观测或声称模型达到投稿接收标准。英文稿仍需目标期刊要求、作者信息、经作者核查的文献与长期归档版本。

海洋业务验证文献指出检验体系应明确观测与产品的关系、验证尺度及不确定性：[Ocean forecasting validation](https://sp.copernicus.org/articles/5-opsr/16/2025/)。独立 SST 基准资料还需要考虑卫星观测时刻与海表皮层温度差异：[SST CCI 验证说明](https://pmc.ncbi.nlm.nih.gov/articles/PMC10980736/)。这些文献支持上述设计方向，并不能替代本研究缺失的独立观测。
