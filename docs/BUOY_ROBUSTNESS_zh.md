# 浮标平台依赖与稳健性检查

更新：2026-10-30。这是查看已有结果后的描述性检查。沿用此前接受的浮标记录、匹配规则和冻结预测，没有重新训练、筛选模型或追加显著性检验。

## 新发现

- 黄海源区三十天 EOF–ExtraTrees 原改善为 **12.11%**。逐一排除全部 25 个夜间平台类型/标识符组合后，改善为 **11.20%—13.29%**；排除整类平台后为 11.76%—18.95%。在这组已观测支持上，优势没有依赖某一个平台。
- 东海北部三十天异常岭回归/树迁移，原来相对逐格点源 AR(1) 的改善为 **−21.17% / −22.40%**。逐平台排除后仍为 **−24.21% 至 −17.78% / −25.77% 至 −18.43%**；整类排除也都为负。新增检查没有确认复杂迁移优势。
- **平台总数不等于采样多样性。** 目的区夜间虽有 29 个类型/标识符组合，前三个占原评分权重 **68.03%**，最大一个为 23.81%；源区前三个占 23.75%。这些是实际评分权重，不能把全部原始记录视为独立样本。
- 删除类型 4 后，源区/目的区仅剩 **231 / 288 个夜间日期**，原来为 1,036 / 1,051 天。这些大幅缩小的样本不能代表原来的完整年份或全海域。单个平台删除最多分别丢失 36 / 40 天；每次都保留同日期参照。

所有区间都是实际排除案例的最小值与最大值，**不是置信区间**。不能据此追加显著性或声称获得新独立观测。平台标识也不保证对应统计独立的物理设备。

## 计分与可核对材料

1. 每条记录计算平方、绝对和带符号误差，先在同一平台同一天平均，再在同日平台间平均，最后日期等权。
2. 逐一排除每个平台组合及每个平台类型，重新分配剩余平台权重；没有记录的日期不填补。
3. 每次同时报告“原全部平台在完全相同剩余日期”的分数，区分日期变化与同日期内平台变化。模型和基线始终共享排除规则与日期。
4. 另报整个期间每个平台等总权重的结果。这改变了评价对象，没有替代原来的日期等权主分数；源区三十天树模型在该权重下改善为 14.10%，目的区岭/树为 −15.46% / −17.03%。
5. 保留源区七种、目的区十三种方法，全部三个步长、昼夜、浮标及同点 OISST 的结果。目的区同时保留三个固定参照，共 **16,734 条排除对照**；没有挑选有利平台。

审阅结果在 [`paper/buoy_robustness/results/`](../paper/buoy_robustness/results/)：完整原分数、逐年结果、平台权重、全部排除对照和汇总。逐项排除表采用无损 `deletion_metrics.csv.gz`，解压即 CSV；本地 `data/processed/buoy_robustness/` 保留未压缩版本。新增图为 300 dpi PNG 与 SVG，英文补充 S15 有方法、表 S20/S21 和图 S11。

新增程序首先重算了源区 **87,150** 行、目的区 **164,190** 行旧浮标逐日模型/步长/目标分数，三种损失在当前环境均精确相同。这些 **251,340 行计分不是独立观测数**。268 份旧阶段文件在运行前后均保持原哈希；审计记录了输入、运行版本与程序哈希。

复现：先完成已有源区及目的区计分，再运行 `python -m src.buoy_robustness` 与 `python -m src.publication_delivery`。本轮无需下载新观测。原始质控的共同参考、潜在 OISST 输入重叠、2025 年以后人工监测变化与相邻子区边界仍然适用。

## 对论文的作用

本轮补强的是“结论是否由某个平台支配”和“浮标覆盖是否被记录数夸大”两个证据问题。源区的描述性优势及目的区的失败方向都保留，但目的区权重集中必须在正文可见。原卫星统计家庭和公开锁定顺序保持原义；这次检查没有解决独立真值、物理因果、业务强迫对照或中科院一区录用问题。
