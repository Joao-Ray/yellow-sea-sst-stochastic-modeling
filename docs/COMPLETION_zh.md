## 一条命令复现

准备 Python 3.11 并安装 requirements.txt 后：

```bash
python -m src.research
```

第一次运行下载约 47.7 MiB 的区域 SST 文件，以及约 1 MiB 的官方海域多边形。
后续校验缓存后复用。结果位于 `data/processed/research/`：

- `完整研究报告.html`：自包含中文报告，图片已嵌入，可以单独分享。
- `完整研究报告_zh.md`：可编辑报告。
- `manuscript_zh.md`：论文初稿，图表与数值来自此次固定输出。
- `metrics.csv`：216 组测试成绩。
- `yearly_metrics.csv`、`block_sensitivity.csv`、`residual_diagnostics.csv`：稳健性与诊断。
- `predictions.csv`、`calibration_radii.csv`、`training_residuals.csv`：逐条复核。
- 三个区域的每日 CSV、`grid_masks.csv`、`data_quality.csv`：数据质量与空间规则。
- `research_config.json`、`protocol.json`、`models.json`、`checksums.json`：设计、来源、系数和校验。

配置固定在 `configs/research.json`。更改配置应使用新的输出目录；程序拒绝覆盖不同设计的已有输出。

## 本次结果摘要

主区域 2023–2025 年，异常持续性 1/7/30 日 RMSE 为 0.1643/0.6121/0.9240℃。
趋势谐波岭回归为 0.1279/0.5546/0.7905℃；本次技能约为 22.2%/9.4%/14.4%。
趋势谐波 AR 的 30 日 RMSE 为 0.7873℃，经验区间覆盖 96.3%，原始高斯区间为 90.8%。

这些是具体时期的探索结果。2017–2019 年主区域的趋势模型 30 日技能为负，
说明最近时期的改进不能推广到任意历史或未来。所有区域、时期与块长结果均保留。

## 项目完成与研究限制

上述工程与探索研究内容已完成。以下是结果适用范围，而不是待补写的数据或功能：

- IHO 定义包含渤海；它不是排除渤海的狭义黄海。
- 初次试验测试成绩已被查看，本扩展不能作为全新确认性研究。
- 区域重叠、训练期重叠，多重比较未校正；块区间依赖近似平稳性。
- 经验校准受历史误差与时间变化影响，不保证未来 95% 覆盖。
- 线性趋势外推和区域平均简化了物理过程，不能支持因果结论。
- 论文是可审阅初稿，正式投稿还需要作者、目标期刊与科学审查。

本地 macOS 仍出现一条 netCDF4/NumPy 二进制尺寸警告；IO、数值一致性、70 项测试
与完整实验均通过。警告未被隐藏。原始边界从供应方获取，不纳入仓库或镜像分发。
